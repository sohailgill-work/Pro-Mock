# Pro-Mock

## Preview locally

If double-clicking `index.html` is blocked by your browser security settings, run a local server:

```bash
cd /workspace/Pro-Mock
python3 -m http.server 8080
```

Then open:

- http://localhost:8080/index.html

## Quick checks

```bash
# Confirm file exists
ls -lh index.html

# Optional: serve on another port
python3 -m http.server 3000
```
